An accessible block theme with a dark "Old Arnie" look, seven style variations, and patterns made from core blocks.

== Description ==

ArneIron Lite is a full-site-editing block theme. Its default "Old Arnie" style is a near-black canvas with a signal-red accent; seven more style variations (among them ArneIron Light) change the whole palette in one click under Appearance > Editor > Styles.

* Templates for the blog, single posts (including a "Scroll Story" post template with a sticky image panel), pages (default, full width, with sidebar, landing), archives, search and 404.
* A ready front page: while Settings > Reading shows your latest posts, the front page is a hero, three feature cards and the latest posts, with placeholder text you replace in the Site Editor. Nothing is imported into your site.
* Header, mobile header with a menu drawer, and footer, all made from core blocks.
* About 85 block patterns made from core blocks only: heroes, features, pricing, testimonials, FAQs, statistics, team, call-to-action and content sections. Adding a new page offers the About, Landing and Pricing page layouts.
* WooCommerce styling. With WooCommerce active, its account link and mini-cart appear in the header and the menu drawer; with Polylang active, a language switcher appears there. Without those plugins nothing of theirs is added.
* Accessibility: a skip link, visible keyboard focus, a keyboard-operable mobile menu and AA contrast in every style variation; see accessibility.txt.

The theme registers no blocks, shortcodes, post types or roles, installs no plugins, and makes no requests to external services.

= Demo =

See ArneIron Lite on a live site: https://demo.arneiron.net/ (with the free ArneIron Blocks plugin active).

= Recommended plugin =

ArneIron Blocks (free, from WordPress.org) adds design blocks that match this theme: hero, call to action, feature cards, FAQ, how it works, price table, stat strip, testimonial, gallery, carousel, latest posts, WooCommerce products and more. Appearance > ArneIron Lite links to it in Plugins > Add New; installing it is up to you, and the theme works fully without it. With the plugin active, the same page offers the plugin's one-click demo content (the pages, posts, photos and menu of the demo site, removable in one click).

= ArneIron Pro =

ArneIron Pro is the commercial edition of this theme (https://arneiron.net/pro/). Nothing in ArneIron Lite is locked or time-limited.

== Frequently Asked Questions ==

= Does the theme need a plugin? =

No. Every template, template part and pattern uses core blocks only.

= Is there demo content to import? =

No import is needed. The front page shows a starter layout made from the theme's patterns while Settings > Reading shows your latest posts; edit it in Appearance > Editor > Templates > Front Page (Latest Posts). New pages offer the theme's page layouts. Nothing is added to your posts, pages or media.

= Where are the theme's settings? =

In the Site Editor (Appearance > Editor): Styles for colours, fonts and layout, Patterns and Template Parts for the header and footer, Templates for page layouts. Appearance > ArneIron Lite has a short getting-started page.

= Does the theme collect any data? =

No. It sets no cookies, loads nothing from other servers (its fonts are bundled), and stores one option, `arneiron_lite`, which only remembers that the welcome notice was shown.
